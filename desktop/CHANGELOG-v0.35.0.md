# BC2 Cold Wallet Desktop v0.35.0

- Onboarding auf zwei klare Aktionen umgestellt: Create New Wallet und Recovery Wallet.
- Beide Aktionen sind nur bei verbundener Hardware aktiv.
- Setup-Seite kompakter gestaltet; Recovery-Hinweis wird nicht mehr unterhalb der Karte abgeschnitten.
- Recovery-Wörter bleiben gemäß Cold-Wallet-Sicherheitsmodell außerhalb der Desktop-App.
- Recovery-Button bereitet den separaten Hardware-Recovery-Flow vor; die eigentliche 12-Wort-Eingabe auf Hardware folgt im nächsten Schritt.
