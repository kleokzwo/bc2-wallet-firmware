# BC2 Cold Wallet v0.42.1

- Recovery is desktop-assisted only: enter 12/24 BIP39 words on desktop.
- Removed hardware fingerprint/word confirmation instructions from the flow.
- Existing wallet: current 4-digit device PIN authorizes replacement.
- Fresh device: create and confirm a new 4-digit PIN; restore then completes automatically.
- Recovery mnemonic is not persisted or logged by the desktop.
