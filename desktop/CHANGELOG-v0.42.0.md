# v0.42.1

- Added SSL Electrum synchronization for known public receive addresses.
- Dashboard now shows confirmed and unconfirmed BC2 balances side by side.
- New confirmed receive addresses are saved as public metadata and synchronized automatically every 30 seconds.
- Settings can import an older receive address created before v0.42.1, so existing test payments are visible too.
- Seed/private keys remain on hardware; only public addresses are used for blockchain lookup.
