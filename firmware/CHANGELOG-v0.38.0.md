# BC2 Firmware v0.41.0

- Recovery no longer asks the user to navigate or confirm mnemonic words on the E-Paper.
- Existing wallet recovery requires the existing 4-digit PIN and preserves that PIN.
- Fresh-device recovery asks only to create/confirm a new 4-digit PIN.
- Wallet restore runs automatically after successful PIN authorization.
- New-wallet creation remains hardware-only and still shows the generated recovery words on-device.
