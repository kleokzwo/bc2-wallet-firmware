# BC2 Firmware v0.32.2 Recovery

This build intentionally returns to the proven v0.29.7 hardware path.

Changes are deliberately minimal:

- hardware PIN is exactly 4 numeric digits
- old v0.29.x six-digit PIN record is removed once
- if no valid 4-digit PIN exists, the device boots directly into `PIN ANLEGEN`
- USB/display/button code otherwise remains the v0.29.7 known-good implementation
- Factory Reset is intentionally deferred until PIN + USB stability is confirmed

No wallet seed is generated or persisted by this recovery build.
