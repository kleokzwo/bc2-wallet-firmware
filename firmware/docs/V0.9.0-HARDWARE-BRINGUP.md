# v0.9.0 – Hardware Bring-up

## Verbindliche Zielplattform
Waveshare ESP32-S3-ePaper-1.54, Display 200×200, ESP-IDF 5.5.0 oder neuer.

## Geliefert
- separates ESP-IDF-Projekt
- C17-HAL auf ESP32-S3: Zeit, Hardware-RNG und NVS
- Boot-Referenz über den gemeinsamen Device-UI-Renderer
- versioniertes, begrenztes USB-Nachrichtenformat mit Hosttest
- Wi-Fi und Bluetooth werden nicht initialisiert
- Boardprofil unterscheidet V1/V2 ausdrücklich

## Sicherheitsgrenze
Waveshare dokumentiert nicht austauschbare V1/V2-Beispiele. Der GPIO-Treiber für Display und Tasten bleibt deshalb in v0.9.0 absichtlich deaktiviert, bis die Revision auf der realen Platine bestätigt wurde. Die Firmware protokolliert Display-Frames über USB-Serial/JTAG, schreibt aber noch nicht auf das Panel. Das ist kein fertiger Displaytreiber.

## Build
```bash
./scripts/build-hardware.sh
```

## Danach auf echter Hardware
1. Rückseite auf `V2`-Aufdruck prüfen.
2. ESP-IDF 5.5.x aktivieren.
3. `idf.py -p /dev/ttyACM0 flash monitor` ausführen.
4. Bootprotokoll dokumentieren.

## Nicht enthalten
Seed, PIN-Speicherung, Signierung, Funk, OTA, produktives USB-Wallet-Protokoll und sichere Schlüsselspeicherung.
